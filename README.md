# Tsukiro

Статический многостраничный сайт: HTML, CSS и JavaScript. Сборка и сервер не нужны.

- index.html — главная
- catalog.html — каталог с поиском, жанрами и сортировкой
- saved.html — список «На потом» (localStorage)
- anime.html?id=frieren — отдельная страница тайтла
- about.html — о сайте
- js/data.js — данные каталога
- images/ — локальные постеры

## GitHub Pages

Загрузите содержимое этой папки в корень публичного репозитория. В Settings → Pages выберите Deploy from a branch, main, /(root). Все ссылки относительные и работают на адресе /имя-репозитория/.

Домен пока не привязан: файл CNAME не создан. Сначала проверьте временную ссылку Pages с VPN и без него.

Список сохраняется только в текущем браузере. Видео и учётные записи не предусмотрены. Изображения: MyAnimeList, Studio Ghibli. Шрифт Golos Text встроен в CSS.
