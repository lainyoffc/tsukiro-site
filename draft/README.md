# Tsukiro — черновик одним HTML

## Выбор следующих идей

`ideas.html` — самостоятельная панель выбора: 15 предложений с эскизами, три направления главной, приоритеты и копирование результата для обсуждения в чате. Скачайте файл и откройте локально. Никакие функции не внедряются автоматически и опубликованный сайт не меняется.

Референсы прочитаны по доступному HTML:

- https://anivox.fun/ — блоки главной и ссылки на /schedule, /seasons, /collections, /rooms.
- https://animeon.cc/ — тематические ряды, поиск, ссылки на сервисы.
- https://animeon.cc/schedule — календарь релизов.
- https://animeon.cc/collections — подборки по темам и настроению.
- https://senku.one/ — разделы онгоингов, анонсов, фильмов и лучших тайтлов.
- https://senku.one/anime/52991 — серии и блок похожих историй.

Полный визуальный обход и проверка авторизованных функций референсов недоступны. Эскизы — собственная адаптация под Tsukiro; идеи дополнены предложениями, явно помеченными как авторские.

Скачайте `index.html` через Download raw file в GitHub и откройте в браузере. CSS, JavaScript, шрифт и основные постеры встроены в файл. Сборка, свой сервер и подключение к ChatGPT не требуются. Календарю необходим интернет: расписание и постеры для новых тайтлов запрашиваются у Shikimori.

## Что добавлено

- Календарь ближайших серий: дни недели, переход между доступными неделями, местный часовой пояс устройства, фильтр «Мои аниме» и кнопка «Следить». В этот фильтр входят отслеживаемые тайтлы календаря и тайтлы из личного списка, у которых совпадают идентификаторы. Уведомления не отправляются.
- Каталог: жанр, поиск русского/английского названия, диапазон годов, студия, формат и максимальное число серий. Данные о сериях и студии относятся к выбранному сезону.
- Личный список: «Хочу посмотреть», «Смотрю», «Просмотрено», «Брошено», вкладки с количеством тайтлов.
- Оценка 1–10 и заметка до 2000 символов. Изменения сохраняются сразу. При удалении из списка заметка и оценка остаются.
- Подробности: персонажи, сезоны и порядок просмотра, прямые ссылки вида `index.html#anime/frieren`.
- Случайный выбор: формат, жанр, лимит серий/минут, исключение просмотренного и брошенного, выбор только из запланированного. Также учитываются фильтры текущего каталога.
- Мобильное нижнее меню, крупные элементы управления, поддержка safe area и reduced motion.

Хранение — localStorage текущего браузера и origin. Данные не переносятся между доменами, браузерами и устройствами. При запрете постоянного хранения интерфейс сообщает, что данные доступны только в этой вкладке. Старый список `tsukiro-watchlist` автоматически читается в качестве списка «Хочу посмотреть», если новая библиотека ещё не создана.

В каталоге семь тайтлов. Перечни сезонов ограничены указанными произведениями и не заявляют полноту всех последующих релизов. Видео и аккаунты не добавлены.

Календарь использует публичный `https://shikimori.io/api/calendar?censored=true`. Источник показывает ближайшую объявленную серию каждого тайтла, а не полный архив; расписание, озвучка и доступность эпизодов могут меняться. При успешной загрузке ответ временно сохраняется в браузере. При сбое не более суток показывается сохранённая версия с пометкой о времени обновления, если она есть; иначе отображается ошибка и кнопка повторной загрузки. Идентификаторы отслеживаемых тайтлов хранятся локально отдельно от основного списка. На 9 ноября 2026 года проверены ответ API и разрешение CORS для `Origin: null`; доступность может отличаться у разных провайдеров.

## Проверки

Проверены синтаксис, разбор CSS, фильтры и пустые состояния, статусы и сохранение оценок/заметок, перенос старого списка, повреждённое хранилище, прямые ссылки на тайтлы, случайный выбор, запуск через file://, формат ответа календаря, навигация по дням и неделям, избранное, безопасная обработка внешнего текста, ошибка сети и актуальный/устаревший кэш. Визуальная проверка в настоящем браузере в этой среде недоступна.
