# Tsukiro — черновик одним HTML

Скачайте `index.html` через Download raw file в GitHub и откройте в браузере. В файле находятся CSS, JavaScript, шрифт и все изображения. Сборка, сервер, внешние запросы и подключение к ChatGPT не требуются.

## Что добавлено

- Каталог: жанр, поиск русского/английского названия, диапазон годов, студия, формат и максимальное число серий. Данные о сериях и студии относятся к выбранному сезону.
- Личный список: «Хочу посмотреть», «Смотрю», «Просмотрено», «Брошено», вкладки с количеством тайтлов.
- Оценка 1–10 и заметка до 2000 символов. Изменения сохраняются сразу. При удалении из списка заметка и оценка остаются.
- Подробности: персонажи, сезоны и порядок просмотра, прямые ссылки вида `index.html#anime/frieren`.
- Случайный выбор: формат, жанр, лимит серий/минут, исключение просмотренного и брошенного, выбор только из запланированного. Также учитываются фильтры текущего каталога.
- Мобильное нижнее меню, крупные элементы управления, поддержка safe area и reduced motion.

Хранение — localStorage текущего браузера и origin. Данные не переносятся между доменами, браузерами и устройствами. При запрете постоянного хранения интерфейс сообщает, что данные доступны только в этой вкладке. Старый список `tsukiro-watchlist` автоматически читается в качестве списка «Хочу посмотреть», если новая библиотека ещё не создана.

В каталоге семь тайтлов. Перечни сезонов ограничены указанными произведениями и не заявляют полноту всех последующих релизов. Видео и аккаунты не добавлены.

## Проверки

Проверены синтаксис, разбор CSS, фильтры и пустые состояния, статусы и сохранение оценок/заметок, перенос старого списка, повреждённое хранилище, прямые ссылки на тайтлы, условия случайного выбора, запуск через file:// и отсутствие внешних ресурсов. Визуальная проверка в настоящем браузере в этой среде недоступна.

Это черновик в ветке `draft/single-html-features`. Ветка Pages `main` не обновляется.
